# Tide Duty

> Two players run one dam with no one allowed to panic.

A local co-op water puzzle where one player raises the left valve and the other lowers the right valve. If a player freezes, the other inherits both valves for a terrifying minute.

## Features
- Split keyboard or dual controller valve controls with asymmetric water flow
- Flood waves that force one player to sacrifice a safe room
- Freeze inheritance when a player stops input, transferring both controls
- Seaweed coin economy from rescued crates to buy valves or sandbags

## Stack
- Phaser
- TypeScript
- Howler.js

## Getting started
```
npm install && npm run dev
```
